# 作品説明動画 台本・デモシナリオ(3分以内)

## 撮影環境

- **録画ツール**: OBS Studio(推奨)またはWindows標準の画面録画
- **ターミナル**: Windows Terminal(推奨設定: 透過オフ・大きめフォント・ダークテーマ)
- **解像度**: 1920x1080 / 60fps / ウィンドウキャプチャ(ターミナルのみ)
- **BGM・効果音**: 任意(音量はナレーションの下に。無断使用不可のものを使わない)
- **動画ファイル**: MP4(H.264)、3分以内

## 構成サマリ(合計 約2:50)

| 時間 | セクション | 内容 |
|------|-----------|------|
| 0:00-0:15 | タイトル | 作品名+一言コンセプト |
| 0:15-0:50 | 基本操作 | 起動・スクロール・目次ジャンプ |
| 0:50-1:30 | レンダリング | コード・テーブル・アラート・タスクリスト |
| 1:30-2:00 | ライブリロード | エディタで編集→自動更新 |
| 2:00-2:30 | パフォーマンス | 実測値の表示(コマンド実演) |
| 2:30-2:50 | まとめ | アピール+リポジトリURL |

## 詳細シナリオ

### 0:00-0:15 タイトル

**画面**: タイトルテキストを静止画 or 動画内テロップで表示
**テロップ**: 「mdv - 超軽量ターミナル向けMarkdownビューア」
**ナレーション**:
「mdv。ターミナル上で動く、超軽量なMarkdownビューアです。
起動は約30ミリ秒、メモリは約8メガバイト。ブラウザもIDEも必要ありません。」

### 0:15-0:50 基本操作

**画面**: Windows Terminalで `mdv examples/sample.md` を実行→即座に表示
**ナレーション**:
「Markdownファイルを開くだけで、見出しやコードブロックが美しくレンダリングされます。」

**キー操作シナリオ**(時間と操作を合わせて録画):

| 時刻 | 操作 | 画面の説明 |
|------|------|-----------|
| 0:20 | `j` × 数回 | 下にスクロール |
| 0:27 | `k` × 数回 | 上にスクロール |
| 0:32 | `t` | 目次(Table of Contents)が右側に表示 |
| 0:35 | `j`/`k` で項目選択→`Enter` | 「Installation」へジャンプ |
| 0:42 | `t` | 目次を閉じる |
| 0:45 | `?` | ヘルプ画面(キーバインド一覧)を表示 |
| 0:48 | `?` | ヘルプを閉じる |

**ナレーション(0:32付近)**:
「`t`キーで目次が開きます。`Enter`で見出しへジャンプ。
`?`でキーバインドの一覧も確認できます。」

### 0:50-1:30 レンダリング紹介

**画面**: `sample.md` の該当箇所へスクロールして順に映す
**キー操作**:

| 時刻 | 操作 | 画面の説明 |
|------|------|-----------|
| 0:50 | `PageDown` | GitHub Alerts(NOTE/TIP/WARNING/CAUTION)の色分け表示 |
| 1:00 | `PageDown` | Rust / Python / JavaScriptコードのシンタックスハイライト |
| 1:10 | `PageDown` | テーブル(罫線・列幅・配置) |
| 1:20 | `PageDown` | ネストリスト・タスクリスト(`[x]`/`[ ]`の色分け) |

**ナレーション**:
「GitHub Alertsの色分け、コードのシンタックスハイライト、テーブル、タスクリスト。
日本語を含むテーブルでもレイアウトが崩れません。」

### 1:30-2:00 ライブリロード

**画面**: ターミナルを2つ並べる(左=エディタ、右=mdv)
**操作**: 左のエディタ(メモ帳 or VSCode)で `sample.md` の文字を変更して保存
→ 右のmdvが約0.1秒で自動更新される

**ナレーション**:
「ライブリロードに対応。エディタで保存するたびに、表示が自動的に更新されます。
ドキュメントの執筆や、AIエージェントの出力を眺めるのに最適です。」

### 2:00-2:30 パフォーマンス実測

**画面**: 別ターミナルで計測コマンドを実行して見せる(録画時に実行)

```bash
# 起動時間(100KBのMarkdownを100回起動して平均)
time for i in $(seq 1 100); do mdv large.md -n -q; done

# メモリ使用量(タスクマネージャー or /usr/bin/time -v)
/usr/bin/time -v mdv large.md
```

**テロップ**(画面に表示): 「起動 ~30ms / メモリ ~8MB / バイナリ ~4MB / ブラウザの1/50以下のリソース」

**ナレーション**:
「ブラウザが100〜500メガバイト使うところを、mdvは約8メガバイト。
起動も約30ミリ秒です。SSHでサーバーに接続したままでも、快適に動作します。」

### 2:30-2:50 まとめ

**画面**: リポジトリのURLを表示(端末に `https://github.com/Cinnamobot/markdown-viewer` を表示 or テロップ)
**ナレーション**:
「ターミナルで完結する、軽くて美しいMarkdownビューア。それがmdvです。
ソースコードはGitHubで公開しています。ぜひ手に取ってみてください。」

## 撮影・編集の注意

- **制限時間**: 3分厳守(長すぎると審査対象外の可能性があるため、2:50〜2:59で収める)
- 録画前に一度リハーサルを行い、キー操作のタイミングを確認する
- ナレーションは後から録音し、BGMとの音量バランスを調整
- 動画は**YouTube限定公開**でアップロードし、ProtoPediaとエントリーフォームにURLを記入
- 審査結果公開までは限定公開のままにする
- 動画内で他者の著作物(音楽・画像)を使わない
